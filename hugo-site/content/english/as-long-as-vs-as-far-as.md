## 📖 오늘의 문법: As Long As vs As Far As

둘 다 "~하는 한"으로 해석되지만 쓰이는 맥락이 완전히 다르다.

- **as long as**: **조건(condition)**을 나타낸다. "provided that(~라는 조건 하에)"과 거의 같은 뜻으로, 뒤에 오는 조건이 충족되는 한 앞의 내용이 성립한다는 뜻이다.
  - *As long as you're happy, that's all that matters.* → 네가 행복한 한, 그게 제일 중요해.
- **as far as**: **범위/한도(extent)**를 나타낸다. 주로 "내가 아는 한(as far as I know)", "~에 관한 한(as far as ~ is concerned)"처럼 정보의 한계나 관심 범위를 제한할 때 쓴다.
  - *As far as I know, he already left.* → 내가 아는 한, 그는 이미 떠났어.

구분 팁:
- **as long as** 뒤에는 보통 "조건절(만약 ~라면)"이 온다 — if와 바꿔써도 말이 되는지 확인해보면 쉽다.
- **as far as** 뒤에는 "I know", "I'm concerned", "I can tell" 같은 **인식/의견을 나타내는 표현**이 자주 붙는다.

헷갈리면 이렇게 기억하자: **as long as = 조건**, **as far as = 한계/범위**.

> 💡 **Tip:** "As far as I'm concerned"은 "내 입장에서는", "내가 보기엔"이라는 뉘앙스로, 자기 의견을 조심스럽게 꺼낼 때 아주 유용한 표현이다.

### 예문 5가지

1. **As long as you finish your homework, you can watch TV.**
2. **As far as I know, the meeting starts at 3 PM.**
3. **You can stay here as long as you need to.**
4. **As far as I'm concerned, this project is already done.**
5. **As long as it doesn't rain, we'll have the picnic outside.**
