## 📖 오늘의 문법: 상황이 바뀐 걸 근거로 말할 때, Now That

- **Now that**은 "이제 ~하니까", "~하게 된 이상"이라는 뜻으로, **새로 생긴 상황을 근거**로 어떤 결론이나 행동을 말할 때 씁니다. because나 since와 비슷하게 "이유"를 나타내지만, **그 이유가 방금 막 성립된 변화**라는 뉘앙스가 있다는 점이 다름
- 구조는 간단합니다: **Now that + 주어 + 동사, 주절.** (순서를 바꿔 주절을 먼저 써도 무방) → *Now that the project is finished, we can relax.* / *We can relax now that the project is finished.*
- because는 그냥 "이유"를 대는 느낌이라면, now that은 "예전엔 그렇지 않았는데 **지금은 상황이 달라졌다**"는 변화의 뉘앙스를 담고 있음 → *Because it's raining, we're staying home.* (단순 이유) vs *Now that it's raining, the trip is cancelled.* (상황 변화가 결정적 근거)
- 구어체에서는 that을 생략하고 그냥 **now + 주어 + 동사**로 쓰기도 함 → *Now you mention it, I remember.* (= Now that you mention it)
- 자주 틀리는 포인트: now that 뒤에는 **현재형이나 현재완료**가 자연스럽습니다. 방금 완료된 변화를 말할 땐 특히 **현재완료**가 잘 어울림 → *Now that you've explained it, it makes sense.*

> 💡 **Tip:** "이제 와서 생각해보니" 또는 "이렇게 된 이상"이라고 말하고 싶을 때, because 대신 now that을 써보세요. 변화된 상황을 근거로 삼는다는 느낌이 훨씬 자연스럽게 삽니다.

### 예문 5가지

1. **Now that you mention it, I do remember the email.**
2. **Now that the project is finished, we can relax a little.**
3. **Now that I think about it, that wasn't the best decision.**
4. **Now that she's moved to Seoul, we see each other more often.**
5. **Now that the rain has stopped, let's go for a walk.**
