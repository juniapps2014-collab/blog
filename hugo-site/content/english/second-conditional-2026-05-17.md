## 🔤 오늘의 문법: 가정법 과거 (Second Conditional)

### 📖 개념 설명

**가정법 과거(Second Conditional)**는 현재 또는 미래에 **사실이 아니거나 실현 가능성이 낮은 상황을 가정**할 때 사용합니다.

> **형태:** If + 주어 + 동사의 과거형, 주어 + would/could/might + 동사원형

실제로 일어나지 않은 일이나, 현실과 반대되는 상상을 표현할 때 씁니다.

---

### 📝 단계별 설명

**Step 1 — 기본 구조 파악하기**

```
If + [과거형 동사], [주어 + would + 동사원형]
```

- If 절: 가정하는 조건 (현재 사실과 반대)
- 주절: 그 조건이 충족될 경우의 결과

**Step 2 — be 동사는 were 사용**

주어가 무엇이든 be 동사는 `were`를 씁니다 (격식체).

- If I **were** rich… (If I **was** rich도 일상적으로 허용)
- If she **were** here…

**Step 3 — would / could / might 구별**

| 조동사 | 뉘앙스 |
|--------|--------|
| would | 확실한 결과 ("~할 것이다") |
| could | 가능성 ("~할 수 있을 텐데") |
| might | 불확실한 가능성 ("~할지도 모른다") |

**Step 4 — if 절과 주절 순서**

If 절이 앞에 오면 쉼표(,)를 넣고, 뒤에 오면 쉼표 없이 씁니다.

- **If I had more time,** I would travel the world.
- I would travel the world **if I had more time.**

**Step 5 — 자주 하는 실수 주의**

❌ If I would have time, I call you.  
✅ If I had time, I would call you.

If 절 안에는 `would`를 쓰지 않습니다!

---

### 💬 예문 5가지

1. **If I were the president, I would lower taxes.**  
   (내가 대통령이라면, 세금을 낮출 텐데.)

2. **If she knew the answer, she would tell us.**  
   (그녀가 답을 안다면, 우리에게 말해줄 텐데.)

3. **If we had a bigger office, we could hire more people.**  
   (더 큰 사무실이 있다면, 더 많은 사람을 고용할 수 있을 텐데.)

4. **If it weren't raining, I would go for a walk.**  
   (비가 오지 않는다면, 산책하러 나갈 텐데.)

5. **What would you do if you won the lottery?**  
   (복권에 당첨된다면 어떻게 할 것인가요?)

## 🎯 오늘의 미니 퀴즈

다음 문장에서 틀린 부분을 찾아보세요:

> *If I would have more time, I would study English every day.*

**정답:** *If I **had** more time, I would study English every day.*  
→ If 절 안에는 `would`를 사용하지 않습니다. 과거형 동사(`had`)를 씁니다.
