## 📖 오늘의 영문법: 도치 (Inversion) — 강조·부정어·조건의 어순 뒤집기

### 개념 설명

**도치(Inversion)**란 일반적인 **주어 + 동사** 어순을 **동사(조동사) + 주어**로 뒤집는 문법입니다. 영어에서 도치는 크게 세 가지 상황에서 쓰입니다.

---

#### ① 부정어·제한어가 문두에 올 때 (Negative / Restrictive Inversion)

문장 앞에 부정이나 제한 의미의 부사(구)가 오면 **조동사 + 주어** 순서로 도치됩니다.

| 자주 쓰이는 표현 | 뜻 |
|---|---|
| Never | 결코 ~않다 |
| Not only ... but also | ~뿐만 아니라 |
| Hardly / Scarcely ... when | ~하자마자 |
| No sooner ... than | ~하자마자 |
| Rarely / Seldom | 거의 ~않다 |
| Under no circumstances | 어떤 경우에도 ~않다 |
| Only then / Only after | 그때서야 비로소 |

> **구조:** 부정어 + 조동사 + 주어 + 동사원형

---

#### ② 가정법 도치 (Conditional Inversion) — if 생략

`if`를 생략하고 조동사/be동사를 앞으로 내보내는 격식체 표현입니다.

| if 문장 | 도치 형태 |
|---|---|
| If I were you | **Were I** you |
| If I had known | **Had I** known |
| If it should rain | **Should it** rain |

---

#### ③ 장소·방향 부사(구) 도치 (Place / Direction Inversion)

장소나 방향 부사(구)를 강조하기 위해 문두에 놓을 때 주어와 동사를 도치합니다. (주어가 대명사면 도치 안 함)

> *Here comes the bus.* (O) / *Here it comes.* (O, 대명사라 동사 앞에 옴)

---

### ✏️ 예시 5개

**1. Never — 강한 부정 강조**
- 일반문: *I have never seen such a clean codebase.*
- 도치문: **Never have I seen such a clean codebase.**
  *(이렇게 깔끔한 코드베이스는 본 적이 없다.)*

**2. Not only ... but also — 두 가지를 강조**
- 일반문: *She not only fixed the bug but also refactored the entire module.*
- 도치문: **Not only did she fix the bug, but she also refactored the entire module.**
  *(그녀는 버그를 고쳤을 뿐만 아니라 모듈 전체를 리팩토링하기까지 했다.)*

**3. 가정법 도치 — Had + 주어 + p.p.**
- 일반문: *If we had started the migration earlier, we wouldn't be in this mess.*
- 도치문: **Had we started the migration earlier, we wouldn't be in this mess.**
  *(더 일찍 마이그레이션을 시작했다면, 지금 이 상황은 없었을 텐데.)*

**4. Under no circumstances — 절대 안 된다**
- 일반문: *You should not share your API key under any circumstances.*
- 도치문: **Under no circumstances should you share your API key.**
  *(어떤 경우에도 API 키를 공유해서는 안 됩니다.)*

**5. Only after — 그 이후에야 비로소**
- 일반문: *We only realized the severity of the issue after the system went down.*
- 도치문: **Only after the system went down did we realize the severity of the issue.**
  *(시스템이 다운된 후에야 비로소 문제의 심각성을 깨달았다.)*

> 🎯 **실무 팁:** 도치 표현은 이메일·슬랙 메시지보다는 **기술 발표, 공식 문서, 에러 공지문**에 어울립니다. 예: *"Under no circumstances should users store tokens in plaintext."* / *"Not only does this reduce latency, but it also cuts infrastructure costs."*

## 🗣️ 미국인이 자주 쓰는 영어 표현 10개

### 1. **"Bear with me."**
- 잠깐만 기다려 줘 / 조금만 참아줘.
- 💬 *"Bear with me while I pull up the dashboard — my laptop's being slow."*

### 2. **"That's a wrap."**
- 이걸로 마무리 / 끝났다.
- 💬 *"Great work everyone. That's a wrap on the Q2 sprint."*

### 3. **"On the same page."**
- (서로) 같은 이해/의견을 갖고 있다.
- 💬 *"Before we dive in, I want to make sure we're all on the same page about the timeline."*

### 4. **"Touch base."**
- 잠깐 연락하다 / 간단히 확인하다.
- 💬 *"Let's touch base on Friday to see where things stand."*

### 5. **"Circle back."**
- 나중에 다시 돌아오다 / 나중에 다시 얘기하자.
- 💬 *"That's a good point — let's circle back to it after the demo."*

### 6. **"Drop the ball."**
- 실수하다 / 해야 할 일을 놓치다.
- 💬 *"I totally dropped the ball on sending the follow-up email. My bad."*

### 7. **"On the fence."**
- 결정을 못 내리고 있다 / 어느 쪽도 아직 확실하지 않다.
- 💬 *"I'm still on the fence about which framework to use for the new service."*

### 8. **"Cut to the chase."**
- 핵심만 말하자 / 본론으로 가자.
- 💬 *"We only have 10 minutes, so let me cut to the chase — we're over budget."*

### 9. **"Give a heads-up."**
- 미리 알려주다 / 사전에 귀띔하다.
- 💬 *"Thanks for the heads-up about the API change — saved us a lot of debugging."*

### 10. **"In the loop."**
- (상황·정보를) 공유받고 있다 / 소식 통해 있다.
- 💬 *"Keep me in the loop on the migration progress, please."*
- ↔️ **out of the loop** = 소식을 못 듣고 있다 / 뒤처지다

## 🔗 오늘의 구동사 (Phrasal Verbs) 5개

### 1. **wrap up** — 마무리하다, 끝내다
- 💬 *"Let's **wrap up** the meeting — we're over time."*
- 💬 *"I'm trying to **wrap up** this ticket before EOD."*

### 2. **follow up (on)** — (후속으로) 확인하다, 팔로업하다
- 💬 *"I'll **follow up** with the client after the call."*
- 💬 *"Did you ever **follow up on** that security audit request?"*

### 3. **back up** — (데이터·주장을) 백업하다 / 지원하다 / 뒷받침하다
- 💬 *"Make sure you **back up** the database before running the migration."*
- 💬 *"Do you have data to **back up** that claim?"*

### 4. **come up with** — (아이디어·해결책을) 떠올리다, 생각해내다
- 💬 *"We need to **come up with** a workaround by tomorrow."*
- 💬 *"She **came up with** a brilliant solution in five minutes."*

### 5. **take over** — 인계받다, 넘겨받다, 인수하다
- 💬 *"Jake is leaving the team, so I'll be **taking over** his accounts."*
- 💬 *"Can you **take over** the on-call rotation starting next week?"*
