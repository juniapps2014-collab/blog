## 📖 오늘의 문법: A Number Of vs The Number Of

둘 다 "number"가 들어가지만, 앞에 붙는 관사(a / the)에 따라 **뒤따르는 동사의 수**가 완전히 달라집니다.

- **a number of + 복수명사**는 "여러 개의 ~", "상당수의 ~"라는 뜻으로, 사실상 수량을 나타내는 표현입니다. 진짜 주어는 뒤에 오는 복수명사이므로 **복수동사**를 씁니다.
  - 예: *A number of students are absent today.*
- **the number of + 복수명사**는 "~의 수(數)"라는 뜻으로, 진짜 주어는 "the number" 그 자체입니다. 그래서 **단수동사**를 씁니다.
  - 예: *The number of students has increased this year.*
- 구분하는 가장 쉬운 방법: **a number of = many(많은)로 바꿔도 뜻이 통하면 복수동사**, **the number of = 수치·통계 얘기라면 단수동사**.
- 비슷한 원리가 "a total of"(복수 취급)와 "the total of"(단수 취급)에도 그대로 적용됩니다.
- 헷갈리기 쉬운 이유는 둘 다 "number"라는 똑같은 단어를 쓰기 때문인데, 관사 하나가 문장 전체의 동사 형태를 바꿔버립니다.

> 💡 **Tip:** "a number of"는 뒤의 명사가 진짜 주인공, "the number of"는 "number" 자신이 진짜 주인공이라고 생각하면 헷갈리지 않아요.

### 예문 5가지

1. **A number of employees are working remotely these days.**
2. **The number of employees working remotely has tripled this year.**
3. **A number of issues were raised during the meeting.**
4. **The number of issues raised during the meeting was surprisingly small.**
5. **A number of customers have complained about the delay.**
