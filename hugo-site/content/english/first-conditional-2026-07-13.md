## 📖 오늘의 문법: First Conditional (1형식 조건문) — 실현 가능한 미래 표현하기

### 설명

**First Conditional**은 **"만약 ~한다면, ~할 것이다"** 처럼 **현재 상황에서 실현 가능성이 있는 미래**를 말할 때 쓰는 구문입니다. 가정이 아니라 **실제로 일어날 수 있는 일**에 대해 말하는 것이 핵심 포인트입니다.

**기본 구조**

| If절 (조건) | 주절 (결과) |
|---|---|
| If + 주어 + 현재형 동사 | 주어 + will/can/may/should + 동사원형 |

> If + 현재시제, ... will/can/may + 동사원형

**핵심 규칙**
- if절에는 **미래시제(will)를 절대 쓰지 않습니다.** 현재형 동사만 씁니다. (❌ If it will rain → ⭕ If it rains)
- 주절에는 will 외에도 상황에 따라 can(가능), may/might(약한 확신), should(권유·조언) 등을 쓸 수 있습니다.
- 어순은 자유롭습니다. If절이 먼저 오면 콤마(,)를 쓰고, 주절이 먼저 오면 콤마 없이 이어씁니다.
  - If we finish early, we can grab lunch together.
  - We can grab lunch together if we finish early.

> ⚠️ Second Conditional과 헷갈리지 않기: First Conditional은 "실현 가능성이 있는" 상황(예: 오늘 야근하면...), Second Conditional은 "현재 사실과 반대되는 가정"(예: 내가 CEO라면...)입니다.

### 예문 5가지

1. **If the client approves the proposal today, we will start development next week.**
   → "오늘 클라이언트가 제안서를 승인하면, 다음 주에 개발을 시작할 거예요."

2. **If you don't back up the database, you might lose important data.**
   → "데이터베이스를 백업하지 않으면 중요한 데이터를 잃을 수도 있어요."

3. **We can launch on schedule if the QA team finishes testing by Friday.**
   → "QA팀이 금요일까지 테스트를 마치면 일정대로 출시할 수 있어요."

4. **If the numbers don't add up, we should double-check the report before sending it.**
   → "숫자가 맞지 않으면, 보내기 전에 보고서를 다시 확인해야 해요."

5. **If I have time after the meeting, I'll send you the updated slides.**
   → "회의 끝나고 시간이 되면 업데이트된 슬라이드를 보내드릴게요."

## 🔄 오늘의 구동사 (Phrasal Verbs) 5가지

### 1. **Hash out** — (세부사항을) 논의해서 해결하다, 조율하다
> "Let's hash out the details before we sign the contract."
> (계약서에 서명하기 전에 세부사항을 논의해서 정리하자.)

### 2. **Roll out** — (제품·서비스를) 출시하다, 단계적으로 시행하다
> "We're rolling out the new feature to all users next month."
> (다음 달에 모든 사용자에게 신기능을 출시할 예정이야.)

### 3. **Zero in on** — ~에 초점을 맞추다, 정확히 겨냥하다
> "Let's zero in on the top three issues from the feedback."
> (피드백에서 가장 중요한 세 가지 문제에 집중하자.)

### 4. **Map out** — (계획을) 자세히 세우다, 구체적으로 짜다
> "She mapped out the entire project timeline before the kickoff."
> (그녀는 킥오프 전에 전체 프로젝트 일정을 자세히 짜놓았어.)

### 5. **Touch on** — (주제를) 간단히 언급하다, 다루다
> "The presentation only touched on the budget — we need more details."
> (발표에서 예산은 간단히만 언급했어 — 더 자세한 내용이 필요해.)
