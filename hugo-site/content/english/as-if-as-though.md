## 📖 오늘의 문법: As If / As Though

- **as if / as though**는 둘 다 "마치 ~인 것처럼"이라는 뜻으로 거의 같은 의미로 쓰입니다. **as though**가 약간 더 격식체·문어체에 가까움
- 뒤에 오는 시제가 핵심: **실제로 사실이 아니거나 가정**일 때는 현재 상황이라도 **과거형(종종 were)**을 씀 → *He talks as if he were rich.* (실제로는 부자가 아님)
- 반대로 **사실일 가능성이 있는, 그럴듯한 이야기**를 할 때는 그냥 평범한 시제(현재/미래)를 씀 → *It looks as if it's going to rain.* (실제로 비가 올 수도 있음)
- **과거의 일이 사실이 아니었음**을 말하고 싶으면 **as if + had + p.p.**를 씁니다 → *She acted as if she hadn't heard me.*
- 관용 표현 **as if to say ~**는 "마치 ~라고 말하려는 듯"이라는 뜻으로 몸짓이나 표정을 묘사할 때 자주 쓰임

> 💡 **Tip:** 뻥이거나 가정이면 → 과거형(were), 진짜 그럴듯하면 → 그냥 현재형. 헷갈리면 "사실일까?"를 먼저 물어보세요.

### 예문 5가지

1. **He acts as if he were the boss, but he isn't.**
2. **She looked at me as if I were crazy.**
3. **It looks as if it's going to rain soon.**
4. **He talked as though nothing had happened.**
5. **She shook her head as if to say "no way."**
