## 핵심 개념 설명

### 노출(Exposure)이란?

노출이란 카메라 센서가 빛을 받아들이는 양을 의미합니다. 노출이 부족하면 사진이 어둡게(언더노출), 과하면 밝게(오버노출) 찍힙니다. 적정 노출을 만들기 위해 세 가지 요소—ISO, 조리개, 셔터스피드—를 조합합니다.

---

### 1. ISO — 빛에 대한 센서의 민감도

ISO는 카메라 센서가 빛에 반응하는 감도를 나타냅니다.

| ISO 값        | 특징                          |
| ------------- | ----------------------------- |
| ISO 100~200   | 노이즈 최소, 밝은 환경에 적합 |
| ISO 400~800   | 실내/흐린 날씨에 적합         |
| ISO 1600~3200 | 어두운 환경, 노이즈 증가      |
| ISO 6400 이상 | 야간 촬영, 노이즈 많음        |

**소니 팁:** α 시리즈는 `MENU → 카메라 설정 1 → ISO` 에서 조정하거나, 전면 다이얼을 직접 돌려 빠르게 변경할 수 있습니다. Auto ISO를 사용할 때는 최대 ISO 상한선(예: ISO 3200)을 설정해두는 것이 좋습니다.

**예시:** 맑은 날 야외에서는 ISO 100, 실내 카페에서는 ISO 800~1600을 주로 사용합니다.

---

### 2. 조리개(Aperture) — 빛이 들어오는 구멍의 크기

조리개는 렌즈 내부의 조리개 날개가 만드는 구멍의 크기입니다. F값(f-stop)으로 표시하며, **숫자가 작을수록 구멍이 크고 빛이 많이 들어옵니다.**

| F값   | 빛의 양 | 심도(피사계 심도) |
| ----- | ------- | ----------------- |
| f/1.8 | 많음    | 얕음 (배경 흐림)  |
| f/4   | 보통    | 중간              |
| f/11  | 적음    | 깊음 (전체 선명)  |

**예시:** 인물 사진에서 배경을 흐리게 하려면 f/1.8~f/2.8, 풍경 사진에서 전체를 선명하게 하려면 f/8~f/11을 사용합니다.

---

### 3. 셔터스피드(Shutter Speed) — 빛을 받아들이는 시간

셔터스피드는 카메라 셔터가 열려 있는 시간입니다. 빠를수록(1/1000s) 빛이 적게, 느릴수록(1/30s) 빛이 많이 들어옵니다.

| 셔터스피드   | 특징                                |
| ------------ | ----------------------------------- |
| 1/1000s 이상 | 움직임 완전 정지, 스포츠/동물 촬영  |
| 1/250s       | 일반적인 야외 촬영                  |
| 1/60s        | 손떨림 주의 구간 (손떨림 보정 필요) |
| 1/30s 이하   | 삼각대 필수, 빛줄기·장노출 가능     |

**핸드헬드(손持) 촬영 시 법칙:** 셔터스피드는 최소 `1/초점거리` 이상으로 설정합니다. 50mm 렌즈라면 최소 1/50s, 가능하면 1/100s 이상을 권장합니다.

---

### 노출 삼각형의 균형

세 요소는 서로 트레이드오프 관계입니다:

```
밝기를 유지하면서 셔터스피드를 빠르게 하려면
→ ISO를 높이거나, 조리개를 더 열어야 합니다.

배경 흐림(얕은 심도)을 원해서 조리개를 열면
→ 빛이 많이 들어오므로, 셔터스피드를 빠르게 하거나 ISO를 낮춰야 합니다.
```

**실용 공식:**

- 밝은 환경 정석: ISO 100 / f/8 / 1/250s
- 인물 흐림 배경: ISO 400 / f/2.0 / 1/500s
- 실내 자연광: ISO 800 / f/2.8 / 1/60s

## 실습 미션

### 미션 1: ISO 고정, 셔터스피드 변화

M 모드로 설정 후 ISO 400, 조리개 f/5.6 고정. 셔터스피드만 1/30s → 1/125s → 1/500s로 바꾸며 3장을 촬영하고 밝기 변화를 비교하세요.

### 미션 2: 조리개 고정, ISO 변화

창가 또는 조명 앞에서 셔터스피드 1/100s, 조리개 f/4 고정. ISO만 100 → 800 → 3200으로 올리며 촬영하고 노이즈 차이를 100% 확대해서 확인하세요.

### 미션 3: 적정 노출 맞추기

P 모드(프로그램 모드)로 촬영 후 카메라가 선택한 ISO/조리개/셔터스피드 값을 확인하고, 같은 장면을 M 모드로 동일한 값을 직접 입력해서 재현해보세요.

## 오늘의 팁 (소니 카메라 특화)

**소니 α 시리즈에서 노출 확인하는 법:**

1. **라이브 뷰 밝기 반영**: 소니 미러리스는 뷰파인더/LCD에서 실시간으로 노출 결과를 미리 볼 수 있습니다. `MENU → 카메라 설정 2 → 라이브 뷰 표시`를 "설정 효과 반영"으로 설정하세요.

2. **노출 표시기(EV 바) 활용**: 화면 하단의 EV(노출 값) 바가 0에 오도록 설정을 조정하는 연습을 하세요. ±0이 적정 노출입니다.

3. **제브라 패턴 활용**: `MENU → 카메라 설정 2 → 제브라 표시`를 활성화하면 과노출 위험 영역을 줄무늬로 경고해줍니다. 임계값은 100+로 설정 권장.
