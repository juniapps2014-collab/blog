## 핵심 개념 설명

### 소니 α 시리즈 메뉴 구조

소니 α 시리즈(A7, A6000 등)의 메뉴는 크게 다섯 탭으로 구성됩니다:

| 탭            | 아이콘 | 주요 내용                          |
| ------------- | ------ | ---------------------------------- |
| 카메라 설정 1 | 📷1    | 화질, ISO, 화이트밸런스, 포커스    |
| 카메라 설정 2 | 📷2    | 드라이브 모드, 손떨림 보정, 제브라 |
| 네트워크      | 📶     | Wi-Fi, Bluetooth 연결              |
| 재생          | ▶      | 사진 보기, 삭제, 보호              |
| 설정          | 🔧     | 날짜/시간, 언어, 포맷, 버전        |

**빠른 접근 팁:** `MENU 버튼` 을 누른 후 상단 탭을 좌우로 이동하며 원하는 카테고리를 선택합니다. 자주 쓰는 설정은 `Fn(기능) 버튼`에 등록해두면 메뉴 없이 바로 접근 가능합니다.

### 초기 세팅: 날짜/시간 및 기본 설정

처음 카메라를 켜거나 배터리를 교체한 후에는 반드시 날짜/시간을 설정해야 합니다. 사진 파일의 메타데이터(EXIF)에 촬영 시각이 기록되기 때문에 정확한 설정이 중요합니다.

**설정 경로:** `MENU → 설정(🔧) → 날짜/시간 설정`

설정 항목:

- **날짜 형식**: 연/월/일 권장
- **시간**: 현재 시각 입력 (서머타임 적용 지역은 주의)
- **지역**: 거주 지역 선택 (자동 시간 동기화에 영향)

**그 외 초기 세팅 권장 항목:**

- `설정 → 언어` — 한국어로 변경
- `설정 → HDMI 설정` — TV 연결 시 해상도 자동
- `카메라 설정 1 → 파일 형식` — RAW 또는 RAW+JPEG 선택

---

### RAW vs JPEG — 어떤 파일 형식을 선택할까?

#### JPEG

- 카메라 내부에서 자동으로 현상·압축한 이미지
- 파일 크기가 작고 바로 사용 가능
- 후보정 여지가 적음 (이미 데이터 손실 발생)
- 초보자가 부담 없이 시작하기 좋음

#### RAW

- 센서가 읽은 원본 데이터를 그대로 저장
- 파일 크기가 크고 전용 소프트웨어 필요 (Sony Imaging Edge, Lightroom 등)
- 노출·화이트밸런스·색감을 후보정으로 자유롭게 조정 가능
- 화질 손실 없이 최고 품질 유지

#### RAW+JPEG (권장)

학습 초반에는 **RAW+JPEG**를 추천합니다. JPEG로 바로 결과물을 확인하면서, RAW 파일은 나중에 보정 연습용으로 활용할 수 있습니다.

**설정 경로:** `MENU → 카메라 설정 1 → 파일 형식`

| 상황                 | 권장 형식         |
| -------------------- | ----------------- |
| 일상 스냅 / SNS 공유 | JPEG Fine         |
| 인물·풍경 중요 촬영  | RAW 또는 RAW+JPEG |
| 학습 / 보정 연습     | RAW+JPEG          |

## 실습 미션

### 미션 1: 메뉴 탐색

카메라를 켜고 MENU 버튼을 눌러 모든 탭을 한 번씩 탐색하세요. 낯선 항목이 있으면 카메라 설명서(또는 소니 공식 앱 "소니 카메라 가이드")에서 확인해보세요.

### 미션 2: 초기 세팅 완료

날짜/시간, 언어를 올바르게 설정하고, 파일 형식을 RAW+JPEG로 변경하세요. 변경 후 한 장 촬영해서 메모리 카드에 RAW(.ARW)와 JPEG 파일이 모두 생성되는지 확인하세요.

### 미션 3: Fn 버튼 커스터마이즈

`MENU → 카메라 설정 2 → 사용자 정의 키` 에서 Fn 버튼 메뉴에 자주 쓸 항목(ISO, 화이트밸런스, 파일 형식 등)을 등록해보세요.

## 오늘의 팁 (소니 카메라 특화)

**My Menu 기능 활용하기**

소니 α 시리즈는 자주 쓰는 메뉴 항목을 `나의 메뉴(My Menu)`에 최대 30개까지 등록할 수 있습니다.

- **등록 방법:** `MENU → 나의 메뉴 → 항목 추가` → 원하는 메뉴 항목 선택
- **추천 등록 항목:** 파일 형식, ISO, 화이트밸런스, 손떨림 보정, 포맷

메뉴 진입 후 바로 나의 메뉴 탭이 열리도록 설정하면 촬영 준비 속도가 크게 빨라집니다:  
`설정 → MENU 시작 → 나의 메뉴`
