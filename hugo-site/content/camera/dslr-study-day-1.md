# 1일차: 카메라 각 부분 명칭 및 기본 설정 (소니 α 시리즈 기준)

## 오늘의 학습 목표

1. 소니 α 시리즈 카메라의 주요 부분 명칭을 익히고 각 버튼/다이얼의 기능을 파악한다
2. 카메라를 처음 켰을 때 해야 할 필수 초기 설정을 완료한다
3. 카메라를 올바르게 잡는 그립법과 기본 조작 흐름을 몸에 익힌다

## 핵심 개념 설명

### 1. 소니 α 시리즈 외관 구조

소니 α 시리즈(α6000, α6400, α6600, α7 시리즈 등)는 공통적으로 아래 구조를 공유합니다.

#### 전면 (Front)
| 부분 명칭 | 위치 | 기능 |
|---|---|---|
| **렌즈 마운트** | 중앙 | 렌즈를 장착하는 링. 소니 E마운트 또는 FE마운트 |
| **마운트 해제 버튼** | 마운트 옆 | 렌즈를 분리할 때 누르는 버튼 |
| **AF 보조광 / 셀프타이머 램프** | 전면 상단 좌측 | 어두운 환경에서 자동초점 보조 빛 발사 |
| **그립부** | 우측 | 오른손으로 카메라를 잡는 돌출 부분 |

#### 상단 (Top)
| 부분 명칭 | 위치 | 기능 |
|---|---|---|
| **모드 다이얼** | 상단 좌측 | P/A/S/M/Auto/SCN 등 촬영 모드 전환 |
| **전원 스위치** | 모드 다이얼 중앙 또는 주변 | 카메라 전원 ON/OFF |
| **셔터 버튼** | 상단 우측 | 반누름(AF 잠금) → 완전 누름(촬영) |
| **전면 다이얼 (커맨드 다이얼)** | 셔터 버튼 주변 | 셔터스피드, 조리개 값 조절 |
| **C1 버튼 (커스텀1)** | 상단 우측부 | 사용자가 기능을 자유롭게 지정 가능 |
| **내장 플래시** | 상단 좌측 (일부 기종) | 팝업식 플래시 |
| **핫슈** | 상단 중앙 | 외장 플래시 또는 마이크 장착부 |

#### 후면 (Back)
| 부분 명칭 | 위치 | 기능 |
|---|---|---|
| **EVF (전자식 뷰파인더)** | 후면 상단 (α7 시리즈 등) | 눈으로 들여다보며 촬영 구도 확인 |
| **LCD 모니터** | 후면 중앙 | 라이브뷰, 재생, 메뉴 표시 |
| **MENU 버튼** | 상단 좌측 | 카메라 전체 설정 메뉴 진입 |
| **재생 버튼 (▶)** | 후면 좌측 | 촬영한 사진/영상 재생 |
| **삭제 버튼** | 후면 좌측 하단 | 선택한 파일 삭제 |
| **컨트롤 휠** | 후면 우측 | 방향키 + 휠 회전으로 설정값 변경 |
| **중앙 버튼** | 컨트롤 휠 중앙 | 선택 확인 / AF 포인트 지정 |
| **Fn (펑션) 버튼** | 후면 우측 | 자주 쓰는 설정 12가지 빠른 접근 |
| **AEL 버튼** | 후면 우측 상단 | 노출 고정 (Auto Exposure Lock) |
| **AF/MF 전환 버튼** | 측면 또는 후면 | 자동/수동 초점 전환 |

#### 측면 (Side)
| 부분 명칭 | 기능 |
|---|---|
| **USB 단자** | 충전 및 PC 연결 |
| **HDMI 단자** | 외부 모니터/TV 연결 |
| **마이크 단자 (3.5mm)** | 외장 마이크 연결 (일부 기종) |
| **메모리카드 슬롯** | SD 카드 삽입 |
| **배터리 덮개** | 배터리 교체 |

### 2. 카메라를 올바르게 잡는 방법

흔들림 없는 사진을 위한 기본 그립:

- **오른손**: 그립부를 감싸 쥐고 검지는 셔터 버튼 위에 자연스럽게 올린다
- **왼손**: 렌즈 아랫부분을 아래에서 받쳐 지지한다
- **팔꿈치**: 몸통에 붙여 카메라를 안정시킨다
- **숨**: 셔터를 누르는 순간 살짝 숨을 참거나 내쉬며 촬영

> **소니 팁**: 뷰파인더를 사용할 때는 이마를 EVF에 대면 세 번째 지지점이 생겨 흔들림이 크게 줄어듭니다.

### 3. 처음 켰을 때 필수 초기 설정

카메라를 처음 구입했거나 초기화 후에는 아래 항목을 가장 먼저 설정하세요.

#### MENU → 설정(Setup) 탭에서

1. **날짜/시간 설정**
   - MENU → 설정 → 날짜/시간 설정
   - EXIF 메타데이터에 정확한 촬영 날짜가 기록됨
   - 지역 설정도 함께 확인

2. **언어 설정**
   - MENU → 설정 → 언어 → 한국어 선택

3. **디스플레이 밝기**
   - MENU → 설정 → 모니터 밝기
   - 실외에서는 밝게, 실내에서는 낮게 조정

#### MENU → 카메라 탭에서

4. **파일 형식 선택** (내일 심화 학습 예정)
   - JPEG: 바로 사용 가능, 용량 작음
   - RAW: 후보정에 유리, 용량 큼
   - 초보자 추천: **RAW + JPEG** 동시 저장

5. **이미지 크기 설정**
   - MENU → 카메라 → 이미지 크기 → L(대) 선택 권장

6. **손떨림 보정 (SteadyShot)**
   - MENU → 카메라 → SteadyShot → ON

### 4. 모드 다이얼 한눈에 보기

| 모드 | 기호 | 설명 |
|---|---|---|
| Auto (자동) | AUTO | 모든 것을 카메라가 결정 |
| P (프로그램 자동) | P | ISO 외 노출을 카메라가 결정, 일부 조정 가능 |
| A (조리개 우선) | A | 조리개(F값)를 사용자가 설정, 셔터스피드는 카메라가 자동 결정 |
| S (셔터 우선) | S | 셔터스피드를 사용자가 설정, 조리개는 카메라가 자동 결정 |
| M (수동) | M | 조리개·셔터스피드·ISO 모두 사용자가 직접 설정 |
| SCN (씬 선택) | SCN | 인물, 풍경, 스포츠 등 상황별 프리셋 |
| 동영상 | 동영상 | 영상 촬영 모드 |

## 실습 미션

### 미션 1: 카메라 해부학
카메라를 손에 들고 다음 버튼들을 직접 찾아보고 눌러보세요:
- MENU 버튼 → 메뉴 구조 훑어보기 (설정하지 않아도 됨)
- Fn 버튼 → 어떤 설정들이 나타나는지 확인
- 컨트롤 휠 좌/우/상/하 방향 및 회전 조작 느껴보기

### 미션 2: 초기 설정 완료
위에서 안내한 6가지 초기 설정(날짜, 언어, 밝기, 파일형식, 이미지크기, SteadyShot)을 실제로 설정하고 메모해두기

### 미션 3: 모드 다이얼 돌려보기
모드 다이얼을 AUTO → P → A → S → M 순서로 돌리면서 LCD 화면이 어떻게 바뀌는지 관찰하고 간단히 메모하기

## 오늘의 팁

> **소니 카메라 특화 팁**
> 소니 α 시리즈는 **Fn(펑션) 버튼**이 매우 강력합니다. 자주 쓰는 설정 12가지를 한 화면에 배치할 수 있어 MENU를 깊이 들어가지 않아도 됩니다. 오늘은 일단 어떤 항목들이 있는지만 살펴보세요. 커스터마이즈는 26일차에 상세히 다룹니다.
>
> 또한 소니는 **NFC/Wi-Fi 내장 기종**이 많습니다. 스마트폰 앱 **Imaging Edge Mobile**을 미리 설치해두면 나중에 원격 촬영 및 사진 전송에 활용할 수 있습니다.
