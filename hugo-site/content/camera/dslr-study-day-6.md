## 핵심 개념 설명

### 셔터스피드란?

셔터스피드(Shutter Speed)는 카메라 센서가 빛에 노출되는 시간입니다. **1/값** 형태로 표기되며, 숫자가 클수록 노출 시간이 짧아집니다.

| 셔터스피드 | 노출 시간  | 주요 용도                     |
| ---------- | ---------- | ----------------------------- |
| 1/8000s    | 0.000125초 | 강한 햇빛, 초고속 동체        |
| 1/1000s    | 0.001초    | 스포츠, 빠른 동물             |
| 1/500s     | 0.002초    | 달리는 사람, 자동차           |
| 1/250s     | 0.004초    | 걷는 사람, 새 비행            |
| 1/125s     | 0.008초    | 일반 인물 촬영                |
| 1/60s      | 0.017초    | 손떨림 한계선 (표준렌즈 기준) |
| 1/30s      | 0.033초    | 삼각대 필요, 약간의 동체 블러 |
| 1s 이상    | 1초~       | 야경, 광궤적, 폭포            |

### 움직임 표현의 두 가지 방향

**1. 동작 정지 (Freeze Motion)**

빠른 셔터스피드로 움직임을 순간 포착합니다. 스포츠 사진, 물방울 순간 포착 등에 활용합니다.

- 물방울 정지: 1/2000s 이상
- 달리는 사람: 1/500s 이상
- 날아가는 새: 1/1000s 이상

예시: 축구 선수가 공을 차는 순간을 1/1000s로 촬영하면 발과 공이 완전히 정지한 것처럼 포착됩니다.

**2. 모션 블러 (Motion Blur)**

느린 셔터스피드로 움직임의 흐름을 시각적으로 표현합니다. 폭포, 야경 차 광궤적, 댄서의 역동성 표현에 활용합니다.

- 흐르는 물 실크 효과: 1/4s ~ 1s
- 차 광궤적: 10s ~ 30s
- 별 궤적: 30분 이상 (벌브 모드)

### 손떨림 vs 피사체 흔들림

이 두 가지는 결과물이 비슷해 보이지만 원인과 해결책이 다릅니다.

| 구분                        | 원인                 | 해결책                  |
| --------------------------- | -------------------- | ----------------------- |
| 손떨림(Camera Shake)        | 촬영자의 손 움직임   | IBIS, 삼각대, 빠른 셔터 |
| 피사체 흔들림(Subject Blur) | 피사체 자체의 움직임 | 더 빠른 셔터스피드      |

**손 안 떨리는 셔터스피드 공식 (Reciprocal Rule):**

> 최소 셔터스피드 = 1 / (초점거리 × 크롭팩터)

소니 APS-C 바디(크롭팩터 1.5) + 50mm 렌즈 사용 시:
→ 1 / (50 × 1.5) = **1/75s** 이상 권장 → 실제로는 1/100s 이상 사용

### 소니 카메라의 셔터 관련 기능

**IBIS (In-Body Image Stabilization) — 바디 손떨림 보정**

α6600, α7 시리즈 등에 탑재. 최대 5.5스탑 보정 효과. 메뉴에서 `손떨림 보정 > 켜기`로 활성화합니다. 렌즈 OSS와 함께 사용 시 더욱 효과적입니다.

**전자셔터 vs 기계셔터**

- **기계셔터**: 소음 있음, 1/4000s까지 (대부분의 소니 바디)
- **전자셔터**: 무음, 최대 1/8000s 가능. 빠른 피사체에서 롤링셔터 왜곡 주의
- 설정: `카메라 설정 > 셔터 방식`

**ISO 자동 연동 (Auto ISO with Minimum SS)**

M 모드 + Auto ISO 조합 시 `ISO 자동 최저 SS` 설정으로 손떨림 없는 최소 속도를 지정할 수 있습니다.

## 실습 미션

### 미션 1: 물 흐름 모션 블러 촬영

설거지 중 수돗물, 공원 분수 등 물이 있는 곳을 찾아 삼각대(또는 테이블에 카메라를 올려) 고정 후:

- 셔터스피드 **1/500s** → **1/60s** → **1/8s** → **1s** 순서로 같은 피사체 촬영
- 각 결과물을 비교하며 "실크처럼 부드러운" 수치 찾기
- **S 모드** (셔터 우선) 사용, ISO Auto, 조리개 자동 설정

### 미션 2: 움직이는 피사체 정지 포착

길을 걷는 사람, 달리는 반려동물, 지나가는 차량 등 움직이는 피사체 촬영:

- **1/60s, 1/125s, 1/250s, 1/500s, 1/1000s** 각각 촬영
- 어느 속도부터 완전히 정지되어 보이는지 확인
- 연속촬영(드라이브 모드) 활용 시 성공률 높아짐

### 미션 3: 패닝(Panning) 기법 도전

지나가는 자동차나 자전거를 배경은 흐리게, 피사체만 선명하게 촬영하는 기법:

- 셔터스피드 **1/60s ~ 1/125s** 설정
- 피사체와 같은 속도로 카메라를 수평 이동하며 셔터
- AF-C(연속 AF) + 연속촬영 모드 추천

## 오늘의 팁 (소니 카메라 특화)

> **💡 소니 IBIS + 렌즈 OSS 동시 활용 설정**
>
> 소니 바디의 IBIS와 렌즈의 OSS(광학 손떨림 보정)를 함께 켜면 서로 간섭할 수 있습니다. 소니는 이를 자동으로 조율하는 **"통합 손떨림 보정"** 기능을 지원합니다. 메뉴 → `손떨림 보정 > 렌즈 보정 정보` 항목을 확인하여 렌즈 정보가 자동 인식되는지 확인하세요. 인식된 경우 IBIS + OSS 협조 제어가 활성화되어 최대 보정 성능을 발휘합니다.
