## 핵심 개념 설명

### 셔터 우선 모드(S 모드)란?

셔터 우선 모드(S 모드, Shutter Priority)는 **촬영자가 셔터스피드를 직접 설정**하면, 카메라가 적정 노출을 위해 조리개(F값)를 자동으로 조절해주는 반자동 모드입니다.

소니 카메라에서는 모드 다이얼을 **S** 위치에 놓으면 활성화됩니다.

```
내가 설정: 셔터스피드
카메라가 자동: 조리개(F값)
ISO: Auto ISO 사용 시 카메라 자동 / 수동 설정 가능
```

### 셔터스피드의 이해

셔터스피드는 **카메라 센서가 빛에 노출되는 시간**을 의미합니다. 분수로 표기하며, 숫자가 클수록 빠른 셔터입니다.

| 셔터스피드 | 시간 | 효과 |
|-----------|------|------|
| 1/2000s | 매우 빠름 | 새의 날갯짓, 물방울 순간 포착 |
| 1/500s | 빠름 | 달리는 사람, 자동차 정지 |
| 1/125s | 보통 | 걷는 사람, 일반 스냅 |
| 1/30s | 느림 | 흐르는 물 약간 흐림, 손흔들림 주의 |
| 1s 이상 | 매우 느림 | 빛의 궤적, 야경, 실크폭포 효과 |

### 피사체 움직임을 멈추려면 (동체 정지)

빠르게 움직이는 피사체를 선명하게 찍으려면 **빠른 셔터스피드**가 필요합니다.

- **걷는 사람**: 1/250s 이상
- **뛰는 사람 / 자전거**: 1/500s 이상
- **달리는 자동차**: 1/1000s 이상
- **새 / 스포츠**: 1/2000s 이상

> **예시**: 운동회에서 달리는 아이를 찍을 때 S 모드로 1/1000s 설정 → 선명하게 멈춘 순간 포착

### 움직임을 흐리게 표현하려면 (모션 블러)

반대로 **느린 셔터스피드**를 사용하면 움직임을 예술적으로 표현할 수 있습니다.

- **흐르는 물 (자연스러운 흐름)**: 1/15s ~ 1/4s
- **실크 폭포 효과**: 1s ~ 5s
- **자동차 빛의 궤적**: 10s ~ 30s
- **별 궤적**: 수십 분 이상

> **예시**: 분수 앞에서 S 모드로 1/10s 설정 + 삼각대 사용 → 부드럽게 흐르는 물 표현

### 손 흔들림 방지 기준 (소니 손떨림 보정 활용)

손으로 들고 찍을 때는 아래 기준을 참고하세요.

```
안전한 셔터스피드 = 1 / (초점거리 × 크롭 배율)

예: 50mm 렌즈, APS-C(1.5배) 카메라
→ 1 / (50 × 1.5) = 1/75s 이상 권장
```

소니 α 시리즈의 **IBIS(바디 손떨림 보정)** 또는 렌즈의 **OSS** 기능을 켜면 2~5스탑 정도 더 느린 셔터스피드도 안전하게 촬영 가능합니다.

### Auto ISO와 S 모드 조합

S 모드에서 ISO를 Auto로 설정하면 카메라가 조리개와 ISO를 함께 조절합니다. 단, ISO가 너무 높아져 노이즈가 많아질 수 있으니 **ISO 상한값 설정**을 권장합니다.

소니 메뉴 경로:
```
MENU → 카메라 설정 1 → ISO AUTO 최대치 설정
권장: ISO 3200 또는 ISO 6400으로 제한
```

## 실습 미션

### 미션 1: 움직이는 피사체 동체 정지 촬영
- S 모드 설정 후 셔터스피드 **1/500s**로 세팅
- 거리의 자동차, 달리는 사람, 또는 선풍기 날개를 촬영
- 1/1000s, 1/2000s로 바꿔가며 차이를 비교
- **확인 포인트**: 피사체가 선명하게 멈췄는가?

### 미션 2: 흐르는 물 또는 움직임 블러 표현
- 삼각대 또는 안정적인 거치대 필수
- S 모드에서 셔터스피드 **1/10s ~ 1s** 구간 설정
- 흐르는 수돗물, 선풍기, 또는 흔들리는 나뭇잎을 촬영
- **확인 포인트**: 움직임이 부드럽게 흐리게 표현됐는가?

### 미션 3: 적정 노출 확인 연습
- S 모드로 셔터스피드 1/250s 고정
- 밝은 실외 → 어두운 실내로 이동하며 동일한 셔터스피드로 촬영
- 뷰파인더 내 노출 경고 표시 확인 (깜박이는 F값 = 적정 노출 불가 상태)
- **확인 포인트**: 어두운 환경에서 F값이 최대로 열려도 부족할 때 어떻게 되는가?

## 오늘의 팁 (소니 카메라 특화)

**💡 소니 α 시리즈 S 모드 활용 팁**

1. **셔터스피드 다이얼 (전면/후면 다이얼)**: S 모드에서 전면 다이얼을 돌리면 셔터스피드가 변경됩니다. 후면 다이얼로는 노출 보정(EV)을 조절할 수 있어 빠르게 밝기 미세조정이 가능합니다.

2. **전자 셔터 활용**: 소니 미러리스 카메라는 전자 셔터를 지원하여 1/8000s 이상의 초고속 셔터도 무음으로 가능합니다.
   ```
   MENU → 카메라 설정 2 → 셔터 타입 → 전자 셔터
   ```

3. **Hi+ 연속 촬영 모드 조합**: S 모드 + 연속 촬영(Hi+) 조합으로 결정적 순간을 놓치지 않을 수 있습니다. 드라이브 모드 버튼을 길게 눌러 설정하세요.

4. **셔터스피드 경고 확인**: 뷰파인더에서 F값이 깜박이면 현재 셔터스피드로 적정 노출 달성 불가 상태입니다. 이때는 셔터스피드를 늦추거나 ISO를 올리세요.
