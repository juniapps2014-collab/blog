## 핵심 개념 설명

### 화이트밸런스(White Balance)란?

인간의 눈은 어떤 광원 아래에서도 흰 종이를 "흰색"으로 인식하도록 자동 보정합니다. 하지만 카메라 센서는 광원의 색온도에 따라 흰색을 다른 색으로 기록합니다. 화이트밸런스는 이를 보정해 **"흰색을 흰색으로"** 찍히게 하는 설정입니다.

### 색온도(Color Temperature)와 켈빈(K)

| 켈빈(K) 수치 | 광원 | 색감 |
|---|---|---|
| 1,000 ~ 2,000K | 촛불, 일출/일몰 | 매우 따뜻한 주황빛 |
| 3,000 ~ 4,000K | 백열등, 텅스텐 | 따뜻한 노란빛 |
| 4,000 ~ 5,000K | 형광등 | 중성적 흰빛 |
| 5,200 ~ 6,000K | 맑은 날 낮 햇빛 | 자연광 기준 |
| 6,500 ~ 8,000K | 흐린 날, 그늘 | 시원한 파란빛 |
| 8,000 ~ 10,000K | 맑은 하늘(그늘) | 매우 차가운 파란빛 |

**핵심 법칙:** WB 수치를 높이면(높은 K) 사진이 따뜻해지고, 낮추면(낮은 K) 사진이 차가워집니다.

> 예시: 형광등(약 4,000K) 아래에서 AWB를 사용하면 카메라가 녹색 캐스트를 보정하려 하지만 완벽하지 않을 수 있습니다. 이럴 때 형광등 프리셋이나 커스텀 WB를 설정하면 훨씬 자연스러운 색감을 얻을 수 있습니다.

### 소니 카메라 WB 프리셋 종류

소니 α 시리즈의 메뉴 또는 빠른 설정(Fn 버튼)에서 접근할 수 있습니다.

| 프리셋 아이콘 | 명칭 | 적합한 상황 |
|---|---|---|
| AWB | 자동 화이트밸런스 | 대부분의 상황, 빠른 촬영 |
| ☀️ | 낮 햇빛 (Daylight) | 맑은 날 야외 |
| ⛅ | 흐린 날 (Cloudy) | 흐린 날, 약간 따뜻하게 표현 |
| 🌑 | 그늘 (Shade) | 그늘, 더 따뜻하게 보정 |
| 💡 | 텅스텐/백열등 | 실내 백열등 조명 |
| 🔦 | 형광등 (Fluorescent) | 사무실, 형광등 환경 |
| ⚡ | 플래시 (Flash) | 외부 플래시 사용 시 |
| K | 색온도 수동 (MWB) | 정밀한 수동 조절 |
| SET | 커스텀 WB | 회색/흰색 카드 기준 설정 |

### AWB의 한계

자동 화이트밸런스는 편리하지만 단점이 있습니다:
- **일몰/일출**: AWB가 따뜻한 빛을 보정해버려 분위기를 망칠 수 있음 → 수동으로 높은 K값 설정 권장
- **야간 조명**: 혼합 광원(네온+가로등+실내등)에서 AWB가 혼란스러워함
- **연속 촬영 시 색상 불일치**: 프레임마다 WB가 달라져 편집 시 어색함

## 실습 미션

### 미션 1: WB 프리셋 비교 촬영
같은 장소에서 다음 설정으로 각각 1장씩 촬영하세요:
- AWB
- 형광등 프리셋 (또는 텅스텐)
- 맑은 날 프리셋

결과물을 비교하며 색감 차이를 육안으로 확인해보세요.

### 미션 2: 수동 색온도(K) 조절 실습
소니 메뉴에서 화이트밸런스 → **색온도/컬러 필터** 선택 후:
- 2,500K ~ 3,000K로 촬영 → 차갑고 파란 결과물 확인
- 7,000K ~ 8,000K로 촬영 → 따뜻하고 황금빛 결과물 확인

같은 피사체로 두 극단을 비교해보세요.

### 미션 3: 일몰 모드 연출
창문이나 야외에서 황혼/저녁빛을 AWB와 수동 K값(6,000~7,500K)으로 비교 촬영하세요. AWB가 따뜻한 빛을 얼마나 지워버리는지 체감할 수 있습니다.

## 오늘의 팁 — 소니 카메라 특화

### 소니 AWB Lock 활용
소니 α 시리즈에는 **AWB Lock** 기능이 있습니다. 촬영 전 AWB로 색온도를 결정하고 그 값을 잠가두면, 이후 프레임에서도 동일한 화이트밸런스가 유지됩니다. 연속 촬영이나 영상 촬영 시 매우 유용합니다.

설정 방법: Menu → Camera Settings → AWB Lock 또는 커스텀 버튼에 AWB Lock 기능 할당

### RAW로 촬영하면 WB는 나중에 수정 가능
JPEG로 촬영 시 WB가 픽셀에 굽혀져 나중에 수정이 어렵지만, **RAW로 촬영하면 WB를 Lightroom이나 소니 Imaging Edge에서 비파괴로 자유롭게 수정**할 수 있습니다. 촬영 현장에서 WB가 확실하지 않다면 RAW + 나중에 보정이 안전한 선택입니다.
