## 핵심 개념 설명

### ISO란 무엇인가?

ISO는 카메라 센서의 빛에 대한 감도(민감도)를 나타내는 수치입니다. 원래는 필름의 감광도를 나타내던 단위였으나, 디지털 카메라에서는 센서가 빛을 증폭시키는 정도를 의미합니다.

- **ISO 낮음 (100~400)**: 빛을 적게 증폭 → 노이즈 적음, 선명한 화질
- **ISO 높음 (1600~6400)**: 빛을 많이 증폭 → 노이즈 많음, 어두운 환경에서 촬영 가능

### ISO 수치별 특성

| ISO | 적합 환경 | 노이즈 수준 | 화질 |
|-----|-----------|------------|------|
| 100 | 맑은 야외, 스튜디오 조명 | 거의 없음 | 최상 |
| 200 | 밝은 야외 (약간 흐린 날) | 매우 적음 | 매우 좋음 |
| 400 | 흐린 날, 밝은 실내 | 적음 | 좋음 |
| 800 | 어두운 실내, 저녁 | 약간 있음 | 양호 |
| 1600 | 야간 도시, 어두운 실내 | 눈에 띔 | 보통 |
| 3200 | 심야, 무대 공연 | 상당함 | 허용 가능 |
| 6400 | 극단적으로 어두운 환경 | 많음 | 제한적 사용 |

### 소니 α 시리즈의 ISO 특징

소니 α7 시리즈 (풀프레임)는 센서가 크기 때문에 고ISO에서도 상대적으로 노이즈가 적습니다. 반면 α6000 시리즈 (APS-C)는 센서가 작아 고ISO에서 노이즈가 더 빨리 증가합니다.

**소니 카메라 ISO 설정 경로:**
- `MENU → 카메라 설정 1 → ISO`
- 또는 빠른 메뉴 `Fn` 버튼 → ISO 항목

**Auto ISO 설정 팁:**
소니 카메라의 Auto ISO는 최소/최대 범위와 최저 셔터속도를 지정할 수 있습니다.
- `MENU → 카메라 설정 1 → ISO → ISO AUTO 최솟값/최댓값` 설정
- 예: 야외 일반 촬영 시 Auto ISO 범위를 100~800으로 제한

### 노이즈의 종류

1. **휘도 노이즈 (Luminance Noise)**: 밝기 변화로 인한 흑백 점 → 필름 그레인과 유사, 덜 거슬림
2. **색상 노이즈 (Chroma Noise)**: 색상 점들이 무작위로 생기는 노이즈 → 더 눈에 거슬림, 보정으로 제거 필요

## 실습 미션

### 미션 1: ISO 비교 샷 찍기
같은 장면을 ISO 100, 400, 1600, 6400으로 각각 촬영해보세요.

**설정 방법:**
1. M 모드 또는 A 모드로 설정
2. 조리개와 셔터속도 고정 (예: f/4, 1/100s)
3. ISO만 바꿔가며 동일한 피사체 촬영
4. 컴퓨터에서 100% 확대 비교

**체크 포인트:** 어느 ISO부터 노이즈가 눈에 띄기 시작하나요?

### 미션 2: 어두운 환경 ISO 실습
밤 또는 어두운 실내에서 손떨림 없는 사진을 찍어보세요.

**목표:** ISO를 올려가며 셔터속도가 1/60s 이상이 되는 최저 ISO 찾기
1. 삼각대 없이 핸드헬드로 촬영
2. ISO 800부터 시작해서 사진이 흔들리지 않을 때까지 올리기
3. 최종적으로 노이즈와 흔들림의 트레이드오프 확인

### 미션 3: Auto ISO 활용
P 모드 또는 A 모드에서 Auto ISO를 활용해 다양한 밝기 환경을 이동하며 촬영해보세요.

**확인 사항:** 카메라가 선택한 ISO 값이 적절한지 확인하고, 필요 시 수동으로 조정

## 오늘의 팁 (소니 카메라 특화)

> **💡 소니의 멀티샷 NR (노이즈 리덕션) 활용**
> 
> 소니 α 시리즈에는 고ISO 시 여러 장을 연사해 자동으로 합성하는 **멀티샷 NR** 기능이 있습니다.
> `MENU → 카메라 설정 2 → 고감도 NR`에서 `멀티샷 NR`을 선택하면 ISO를 높여도 노이즈를 상당히 줄일 수 있습니다. 단, JPEG에만 적용되며 움직이는 피사체에는 부적합합니다.

> **📌 RAW 촬영 시 노이즈 처리**
> 
> RAW로 촬영하면 노이즈 처리를 후보정에서 직접 조절할 수 있습니다. 소니 Imaging Edge Desktop이나 Lightroom에서 **노이즈 감소 슬라이더**를 사용해 디테일과 노이즈 제거 간의 균형을 직접 찾아보세요.
