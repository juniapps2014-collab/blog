## 핵심 개념 설명

### RAW vs JPEG — 왜 RAW인가?

카메라가 사진을 저장하는 방식은 크게 두 가지입니다.

**JPEG**는 카메라 내부에서 자동으로 현상·압축된 파일입니다. 용량이 작고 바로 공유할 수 있지만, 카메라가 "알아서" 결정한 색과 노출이 이미 구워져 있어 나중에 수정할 여지가 줄어듭니다.

**RAW**는 센서가 받은 빛 정보를 그대로 담은 원본 데이터입니다. 소니 카메라의 RAW 확장자는 `.ARW`입니다. 파일 크기는 크지만 다음과 같은 이점이 있습니다.

- **노출 복구 범위**: JPEG는 과노출·언더노출 복구가 1~2 스톱 수준이지만, RAW는 3~5 스톱까지 살려낼 수 있습니다.
- **화이트밸런스 자유**: 촬영 후에도 색온도를 처음부터 다시 설정하는 것처럼 완벽하게 바꿀 수 있습니다.
- **16비트 색 깊이**: JPEG(8비트)보다 훨씬 섬세한 그라데이션 표현이 가능합니다.

> 💡 예시: 황금 시간대 역광 인물 사진을 JPEG로 찍으면 하늘은 날아가고 얼굴은 어두워집니다. 같은 장면을 RAW로 찍으면 하늘 디테일을 살리면서 얼굴을 밝힐 수 있습니다.

### 소니 Imaging Edge Desktop (무료)

소니 공식 RAW 현상 소프트웨어로, 소니 카메라 파일에 최적화되어 있습니다.

**주요 메뉴 구성**

| 탭 | 기능 |
|---|---|
| Viewer | 폴더 브라우징, 썸네일 확인 |
| Edit | RAW 현상 메인 화면 |
| Remote | PC에서 카메라 원격 제어 |

**Edit 화면 핵심 슬라이더 (오른쪽 패널)**

- **노출 (Exposure)**: 전체 밝기. ±3EV 조절 가능
- **DRO (Dynamic Range Optimizer)**: 소니 독자 기술로 명암부를 자동 보정
- **화이트밸런스 (WB)**: 색온도(K값) 또는 프리셋 선택
- **크리에이티브 스타일**: Vivid·Neutral·Portrait 등 색조 프리파일
- **샤프니스 / 노이즈 감소**: 해상력과 노이즈 균형 조절

### Adobe Lightroom Classic 기초 인터페이스

Lightroom은 현업 사진가들이 가장 많이 사용하는 현상 툴입니다.

**현상 모듈(Develop) 오른쪽 패널 구조**

```
Histogram               ← 현재 노출 상태를 시각적으로 표시
Basic (기본)
  ├─ White Balance       ← 색온도(Temp) + 색조(Tint)
  ├─ Tone
  │    ├─ Exposure       ← 전체 밝기
  │    ├─ Contrast       ← 명암 대비
  │    ├─ Highlights     ← 밝은 부분만 조절
  │    ├─ Shadows        ← 어두운 부분만 조절
  │    ├─ Whites         ← 최고 밝기 (클리핑 방지)
  │    └─ Blacks         ← 최저 어두움 (깊이감)
  └─ Presence
       ├─ Texture        ← 중간 디테일 강조
       ├─ Clarity        ← 로컬 콘트라스트
       └─ Vibrance/Saturation ← 채도 조절
```

**기본 현상 순서 (권장)**

1. 화이트밸런스 먼저 설정 → 색이 맞아야 노출이 보입니다
2. Exposure로 전체 밝기 기준 설정
3. Highlights / Shadows로 세부 조절
4. Whites / Blacks로 명암 범위 확장
5. Texture / Clarity로 디테일 살리기
6. Vibrance로 색감 마무리

---

### 소니 ARW 파일 Lightroom으로 가져오기

1. Lightroom Classic 실행 → **File > Import Photos**
2. 카메라 메모리 카드 또는 폴더 선택
3. **Copy** 모드 선택 (원본을 하드에 복사하면서 임포트)
4. Destination 폴더 지정 → **Import** 클릭
5. Library 모듈에서 임포트된 사진 확인
6. 사진 더블클릭 또는 `D` 키로 Develop 모듈 진입

## 실습 미션

### 미션 1: 같은 장면을 RAW + JPEG 동시 촬영 후 비교
카메라 메뉴에서 **MENU → 촬영 1 → 화질/이미지사이즈 → RAW & JPEG** 설정.  
역광이 있는 실내·외 장면을 찍고, JPEG 원본과 RAW 현상본을 비교해보세요.  
- JPEG: 그대로 사용
- RAW: Shadows를 +80, Highlights를 -60 조절 후 차이 확인

### 미션 2: 화이트밸런스 의도적으로 "틀리게" 촬영 후 RAW로 복원
카메라 WB를 **텅스텐(전구 아이콘, 약 3200K)** 으로 설정한 뒤 낮에 촬영.  
파랗게 나온 사진을 Lightroom에서 WB 슬라이더로 정상 색온도(5500K 내외)로 복원하세요.  
JPEG로 같은 실험을 하면 얼마나 복원이 안 되는지도 비교해보세요.

### 미션 3: 한 장의 RAW로 두 가지 분위기 만들기
같은 ARW 파일을 Lightroom에서 두 번 현상하세요 (Virtual Copy: 사진 우클릭 → Create Virtual Copy).  
- 버전 A: 밝고 따뜻한 분위기 (Exposure +0.7, Temp +500, Shadows +40)  
- 버전 B: 어둡고 차가운 분위기 (Exposure -0.5, Temp -400, Blacks -30)

## 오늘의 팁 (소니 카메라 특화)

**소니 α 시리즈 전용 팁: ARW 압축 방식 선택**

소니는 RAW 파일을 세 가지 방식으로 저장할 수 있습니다.

| 설정 | 용량 | 특징 |
|---|---|---|
| 비압축 RAW | 약 42MB (A7 IV 기준) | 최고 화질, 편집 여지 최대 |
| 압축 RAW | 약 21MB | 화질 손실 거의 없음, 용량 절반 |
| 로스리스 압축 RAW | 약 30MB | 손실 없는 압축 (최신 기종) |

입문 단계에서는 **압축 RAW**로 충분합니다. 메모리 카드와 하드 용량을 아끼면서 RAW의 장점을 그대로 누릴 수 있습니다.  
설정 경로: **MENU → 촬영 1 → 화질/이미지사이즈 → RAW 파일 형식**
