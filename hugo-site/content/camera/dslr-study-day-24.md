## 핵심 개념 설명

### 1. 노출 보정 (Exposure Correction)

RAW 파일은 촬영 후에도 노출을 ±2~3 스탑 수준으로 복구할 수 있다는 것이 JPEG 대비 최대 강점입니다.

**주요 슬라이더와 역할:**

| 슬라이더 | 역할 | 조정 방향 |
|---|---|---|
| **노출 (Exposure)** | 전체 밝기 조절 | 너무 어두우면 +, 너무 밝으면 - |
| **하이라이트 (Highlights)** | 밝은 부분만 조절 | 날아간 하늘 복구: - 방향 |
| **그림자 (Shadows)** | 어두운 부분만 조절 | 얼굴 그림자 살리기: + 방향 |
| **화이트 (Whites)** | 가장 밝은 영역 클리핑 조절 | 히스토그램 오른쪽 끝 확인 |
| **블랙 (Blacks)** | 가장 어두운 영역 조절 | 깊이감 표현: - 방향 |

**실전 팁:** 히스토그램의 양쪽 끝이 잘리지 않도록(클리핑 없도록) 조정하는 것이 기본 원칙입니다. 소니 Imaging Edge Desktop이나 Lightroom에서 Alt(Option) 키를 누른 채 슬라이더를 움직이면 클리핑 영역이 빨간색/파란색으로 표시됩니다.

---

### 2. 화이트밸런스 보정 (White Balance)

카메라가 설정한 색온도가 현장의 빛과 다를 때 후보정으로 수정합니다.

**색온도(Temperature)와 색조(Tint)의 관계:**

- **색온도 슬라이더**: 왼쪽(-) = 차갑고 파란 느낌 / 오른쪽(+) = 따뜻하고 노란 느낌
- **색조 슬라이더**: 왼쪽(-) = 초록빛 제거 / 오른쪽(+) = 마젠타(분홍)빛 추가

**상황별 색온도 가이드:**

| 촬영 환경 | 권장 색온도(K) |
|---|---|
| 맑은 날 야외 | 5500~6000K |
| 흐린 날 / 그늘 | 6500~7500K |
| 일몰 / 황금 시간대 | 3500~4500K |
| 형광등 실내 | 4000~4500K |
| 백열등 실내 | 2700~3200K |

**스포이드 도구 활용:** 사진 안에 순백색 또는 중성 회색 영역을 클릭하면 자동으로 화이트밸런스를 보정해줍니다. 흰 벽, 흰 종이, 회색 카드가 사진에 있다면 가장 정확합니다.

---

### 3. 색조/채도/명도 조정 (HSL 패널)

HSL(Hue / Saturation / Luminance) 패널은 특정 색상만 골라서 색감을 수정하는 강력한 도구입니다.

**3가지 채널:**

- **색조 (Hue)**: 특정 색상의 방향 변경 (예: 하늘색을 더 청량한 파랑으로)
- **채도 (Saturation)**: 특정 색상의 진하기 조절 (예: 피부색 과채도 줄이기)
- **명도 (Luminance)**: 특정 색상의 밝기 조절 (예: 하늘 어둡게 해 구름 부각)

**인물 사진 보정 예시:**
- 오렌지 채도 약간 낮춤 → 피부가 자연스러워짐
- 오렌지 명도 살짝 높임 → 피부가 밝고 화사해짐

**풍경 사진 보정 예시:**
- 파랑/청록 채도 높임 → 하늘/바다가 선명해짐
- 초록 색조를 노란 쪽으로 조정 → 나뭇잎이 더 생생해짐

---

### 4. 색조 곡선 (Tone Curve) 기초

곡선은 특정 밝기 영역의 노출과 색상을 동시에 조절하는 고급 도구입니다.

**S자 커브 (기본 대비 강조):**
- 밝은 영역(오른쪽 위): 위로 올림 → 하이라이트 밝아짐
- 어두운 영역(왼쪽 아래): 아래로 내림 → 그림자 어두워짐
- 결과: 자연스러운 대비감 향상

**필름 룩 (Faded Film Style):**
- 어두운 영역의 왼쪽 끝 포인트를 살짝 위로 올림 → 블랙이 회색으로 들려 바랜 필름 느낌

## 실습 미션

### 미션 1: 역광 인물 사진 밝기 살리기
1. 역광이나 그늘에서 찍은 인물 사진을 RAW로 불러옵니다
2. 하이라이트를 -50 정도로 내려 배경 하늘 복구
3. 그림자를 +50~70으로 올려 얼굴 밝히기
4. 노출을 전체적으로 ±0.3~0.5 스탑 미세 조정
5. 히스토그램 클리핑 없는 상태로 마무리

### 미션 2: 화이트밸런스 3가지 버전 비교
1. 같은 사진을 3가지 다른 색온도(4500K / 5500K / 7000K)로 내보내기
2. 각각 어떤 분위기가 되는지 비교 저장
3. 스포이드 도구로 자동 보정 후 결과 비교

### 미션 3: HSL로 하늘색 강조하기
1. 파란 하늘이 있는 풍경 사진을 불러옵니다
2. HSL 패널 → 파랑 채도 +30, 파랑 명도 -20
3. 청록 채도 +20 추가
4. 보정 전/후 비교 스냅샷 저장

## 오늘의 팁 (소니 카메라 특화)

**소니 RAW(.ARW) 파일 보정 권장 워크플로:**

소니 카메라는 자체 소프트웨어인 **Imaging Edge Desktop**을 무료로 제공합니다. Lightroom 구독이 없다면 Imaging Edge로도 충분한 보정이 가능합니다.

- **Imaging Edge Desktop**: 소니 전용 RAW 엔진 → 소니 색감 그대로 유지, 특히 스킨톤 재현에 강점
- **Lightroom Classic**: 범용성 최고, HSL/곡선 편집 UI가 직관적
- **Darktable (무료 오픈소스)**: Lightroom 대체재, 기능 동등

**소니 픽처 프로파일과 후보정:**
- `Standard` 프리셋으로 찍은 RAW는 대비가 높아 보정 여유가 적음
- 후보정을 많이 하려면 카메라의 크리에이티브 스타일을 **Neutral** 또는 **Portrait**로 설정하고 촬영하면 더 넓은 보정 여유가 생깁니다
