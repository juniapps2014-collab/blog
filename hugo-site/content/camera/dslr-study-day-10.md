## 오늘의 학습 목표

1. M 모드에서 ISO, 조리개(F값), 셔터스피드를 직접 설정하는 방법을 익힌다.
2. 노출 삼각형 세 요소를 수동으로 조합해 원하는 노출값(EV)을 만들어낸다.
3. 소니 카메라의 노출 미터를 읽고 적정 노출을 판단하는 능력을 기른다.

## 핵심 개념 설명

### M 모드란?

**수동 모드(Manual Mode)**는 촬영자가 ISO·조리개·셔터스피드를 모두 직접 결정하는 모드입니다. 카메라가 아무것도 자동으로 바꾸지 않기 때문에 가장 완전한 표현의 자유를 제공합니다. 반면 잘못 설정하면 노출 과다(하얗게 날아감) 또는 노출 부족(어둡게 뭉개짐)이 발생합니다.

### 노출 삼각형 복습

| 요소       | 조절 방향 | 밝아지는 방향    | 어두워지는 방향  |
| ---------- | --------- | ---------------- | ---------------- |
| ISO        | 감도      | 높임 (ISO 1600+) | 낮춤 (ISO 100)   |
| 조리개     | F값       | 낮춤 (F1.8)      | 높임 (F16)       |
| 셔터스피드 | 시간      | 느리게 (1/30s)   | 빠르게 (1/2000s) |

세 요소는 서로 영향을 주기 때문에, 하나를 바꾸면 나머지 두 개로 균형을 맞춰야 합니다.

### 소니 카메라의 노출 미터 읽는 법

뷰파인더 하단 또는 LCD 화면 아래에 **노출 미터(바형 그래프)**가 표시됩니다.

```
- - - [ 0 ] - - -
```

- **중앙(0)**: 카메라가 판단하는 적정 노출
- **왼쪽(−)**: 노출 부족 → 더 밝게 설정 필요
- **오른쪽(+)**: 노출 과다 → 더 어둡게 설정 필요

> **소니 팁**: 소니 α 시리즈는 EVF/LCD에서 실시간으로 최종 노출 결과를 미리 보여주는 **Live View**가 지원됩니다. M 모드에서도 눈으로 직접 확인하면서 값을 조절할 수 있어 필름 카메라보다 훨씬 직관적입니다.

### M 모드 다이얼 조작 방법 (소니 α6400 / α7 시리즈 기준)

- **앞 다이얼(Front Dial)**: 셔터스피드 조절
- **뒤 다이얼(Rear Dial)**: 조리개 조절
- **ISO**: MENU → 카메라 아이콘 → ISO 또는 커스텀 버튼에 할당

> 모델에 따라 다이얼 배치가 다를 수 있습니다. 설명서의 "다이얼 기능" 항목을 확인하세요.

### 적정 노출 조합 예시

**맑은 날 야외(낮)**

- ISO 100 / F8 / 1/500s → 삼각형의 고전적 조합 "Sunny 16"

**실내 인물(창문광)**

- ISO 400 / F2.8 / 1/60s → 적당한 심도 + 흔들림 방지

**야경**

- ISO 1600 / F8 / 2s (삼각대 필수) → 장노출로 빛 궤적 표현

## 실습 미션

### 미션 1: 노출 삼각형 균형 잡기

1. 카메라를 M 모드로 설정한다.
2. 실내 정물(컵, 책 등)을 피사체로 고른다.
3. 먼저 ISO 400 / F5.6 / 1/60s로 찍어본다.
4. **셔터스피드만** 1/30s로 바꾸고 비교 촬영 → 밝아졌는지 확인.
5. **조리개만** F2.8로 바꾸고 비교 촬영 → 심도 변화와 밝기 변화를 함께 관찰.

### 미션 2: 노출 미터 0으로 맞추기

1. 강한 광원(창문) 방향으로 피사체를 놓는다.
2. M 모드에서 노출 미터가 −2 EV인 상태에서 시작한다.
3. 셔터스피드, 조리개, ISO를 조절해 미터를 0으로 이동시킨다.
4. 3가지 다른 조합으로 모두 0을 달성해 보고, 결과물의 차이(심도, 노이즈, 움직임)를 비교한다.

### 미션 3: "Sunny 16" 규칙 적용

1. 맑은 날 야외로 나간다.
2. ISO 100 / F16 / 1/100s 설정으로 촬영한다 (셔터스피드 ≈ 1/ISO).
3. 구름이 낀 날이라면 F8로 변경해 노출을 보완한다.
4. 히스토그램을 확인해 하이라이트가 클리핑되지 않았는지 체크한다.

## 오늘의 팁 — 소니 카메라 특화

**"Zebra" 기능으로 노출 과다 경고 받기**

소니 α 시리즈에는 **Zebra(제브라)** 기능이 있습니다. 설정한 밝기 이상의 영역에 줄무늬 패턴을 오버레이해 노출 과다를 실시간으로 경고합니다.

- 경로: MENU → 카메라 아이콘 → [Zebra 표시] → 레벨 100 설정 (하이라이트 클리핑 방지)
- M 모드에서 특히 유용하며, 인물 피부 노출 관리나 밝은 하늘 촬영 시 필수 도구입니다.

**히스토그램 상시 표시 설정**

DISP 버튼으로 히스토그램 오버레이 화면을 선택해두면, M 모드 실습 중 노출 판단이 훨씬 정확해집니다.
