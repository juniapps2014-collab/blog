# Claude 마스터 커리큘럼 — 개발자 가이드

> 기초부터 고급 프롬프트 엔지니어링 및 API 활용까지 순차적으로 학습합니다.
> 매일 하나의 강의노트가 자동 생성됩니다.

---

## 📚 전체 목차

### Phase 1: 기초 (Day 01–05) — Claude 이해하기
| Day | 주제 |
|-----|------|
| 01 | Claude란 무엇인가? — 모델 개요, 특징, 다른 LLM과의 차이 |
| 02 | 기본 프롬프트 작성법 — 명확하게 요청하는 방법 |
| 03 | 컨텍스트와 대화 흐름 — 멀티턴 대화 설계 |
| 04 | 출력 형식 제어 — JSON, 마크다운, 구조화된 응답 |
| 05 | Claude의 한계와 특성 이해 — hallucination, refusal, cutoff |

### Phase 2: 중급 (Day 06–12) — 프롬프트 엔지니어링
| Day | 주제 |
|-----|------|
| 06 | 역할 지정 (Role Prompting) — system prompt 설계 |
| 07 | Few-shot / Chain-of-Thought 프롬프팅 |
| 08 | XML 태그 활용 — 구조화된 지시문 작성 |
| 09 | 긴 문서 처리 — 요약, 추출, 분석 패턴 |
| 10 | 코드 생성 및 리뷰 프롬프트 |
| 11 | 다단계 추론 (Multi-step reasoning) 패턴 |
| 12 | 프롬프트 평가 및 반복 개선 방법론 |

### Phase 3: API 활용 (Day 13–18) — 개발자 통합
| Day | 주제 |
|-----|------|
| 13 | Anthropic API 기초 — 인증, 기본 요청/응답 구조 |
| 14 | Messages API 파라미터 심화 — temperature, top_p, max_tokens |
| 15 | Streaming 응답 처리 |
| 16 | Tool Use (Function Calling) — 외부 도구 연동 |
| 17 | Vision API — 이미지 입력 처리 |
| 18 | 비용 최적화 — 토큰 계산, 캐싱, 배치 처리 |

### Phase 4: 고급 (Day 19–25) — 프로덕션 적용
| Day | 주제 |
|-----|------|
| 19 | 에이전트 설계 패턴 — ReAct, Plan-and-Execute |
| 20 | Multi-agent 시스템 설계 |
| 21 | RAG (Retrieval-Augmented Generation) 패턴 |
| 22 | 프롬프트 인젝션 방어 및 보안 |
| 23 | 평가(Evals) 프레임워크 구축 |
| 24 | 프로덕션 배포 시 고려사항 — 레이턴시, 재시도, 폴백 |
| 25 | 실전 케이스 스터디 — Sendbird AI Agent 맥락에서의 활용 |
